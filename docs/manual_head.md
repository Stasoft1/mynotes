# МоиЗаметки — руководство пользователя

Версия 0.3.0 · Android 12 и новее (64-разрядные телефоны)

МоиЗаметки — записная книжка для тех, кто ведёт много записей по дням и хочет, чтобы приложение само считало итоги: сколько потрачено, сколько проехано, сколько израсходовано, что пора оплатить или сделать. Это дерево из папок и заметок с шифрованной базой, шаблонами, переменными, напоминаниями и голосовым вводом. Никаких аккаунтов и облака: всё лежит на вашем телефоне.

Руководство написано для тех, кто видит приложение впервые. Если вы хотите сразу попробовать, начните с раздела «Быстрый старт», а к остальному возвращайтесь по мере надобности. Такие же справки (по каждому модулю, по переменным, шаблонам и голосовому вводу) есть **внутри приложения**: Настройки → «Справка», а при первом запуске на пустой базе приложение само создаёт папку «Руководство» с заметками и переходами между ними.

## Быстрый старт за 10 минут

Цель: завести учёт расходов, чтобы папка месяца сама показывала, сколько потрачено.

1. **Создайте папки.** На главном экране нажмите «создать папку» и назовите её «Расходы». Откройте её и создайте папку «2026», в ней — «Ноябрь», в ней — папку дня «21.11.26» (дату пишите числом.месяц.год).
2. **Объявите переменную.** Нажмите и удерживайте папку «Расходы» → «Свойства» → «Переменные» → «+ Переменная». Название — «Сумма», способ — «Сумма». Сохраните.
3. **Заведите шаблон.** Кнопка шаблонов на верхней панели → «+». Название — «Расход», текст:
   ```
   Магазин: 
   Сумма: 
   Примечание: 
   ```
4. **Создайте заметку.** Откройте папку «21.11.26», нажмите кнопку шаблонов и выберите «Расход». Заполните: «Магазин: Пятёрочка», «Сумма: 450».
5. **Посмотрите итог.** Вернитесь в «Ноябрь»: под названием папки видна сумма всех дней. Выше, в «2026», — сумма всех месяцев.
6. **Попробуйте голос.** Нажмите на микрофон и скажите: «Новая заметка расход, магазин Магнит, сумма 320». Приложение найдёт шаблон «Расход» и заполнит поля.

Дальше можно включить модули (Настройки → «Модули») — например, «Бюджет и расходы» построит из таких заметок отчёт по категориям, а «Папка дня» будет сама создавать папку на каждый день.

## 1. Установка

Скачайте файл `MyNotes-версия.apk` и установите его (может понадобиться разрешить установку из неизвестных источников для приложения, через которое вы открываете файл). Новые версии устанавливаются поверх старой, данные сохраняются.

При первой установке в приложении два шаблона («Дата» и «Расход»), **все модули выключены**, а на главном экране лежит папка «Руководство»: это то же руководство в виде заметок со ссылками для перехода между ними. Нужные модули вы включаете сами в Настройках → «Модули» (см. раздел 15). Папку «Руководство» можно удалить, а если она понадобится снова, добавьте её в Настройках → «Справка».

## 2. Первый запуск и безопасность

- При первом запуске нужно придумать **пароль**. Им шифруется вся база (SQLCipher, AES-256). **Если забыть пароль, данные восстановить нельзя** — ни автор, ни кто-либо другой этого сделать не сможет. Запишите его в надёжном месте. Если пароль вам не нужен, нажмите «Продолжить без пароля» (см. ниже).
- Вход можно ускорить **отпечатком пальца** (Настройки → «Безопасность»). Отпечаток только открывает приложение; пароль остаётся главным.
- Приложение **автоматически блокируется** через 30 секунд после ухода в фон. Мгновенно заблокировать можно пунктом «Заблокировать» в меню.
- Скриншоты и запись экрана внутри приложения запрещены, а стандартное облачное резервирование Android для приложения отключено.
- Интернет в ядре приложения не используется. Он нужен только тем модулям, которые вы включите: карта и поиск мест (модуль «Напоминания по месту»), ИИ-разбор голоса (модуль GigaChat). Выключенный модуль ничего никуда не отправляет.

### Пароль можно выключить

Настройки → «Безопасность» → «Защита паролем». Чтобы выключить, понадобится ввести текущий пароль **или подтвердить отпечатком** (удобно, если пароль забыт, а вход всегда по отпечатку). После выключения приложение открывается сразу, без пароля и автоблокировки.

Что важно знать:
- База остаётся зашифрованной, но её ключ хранится в защищённой области телефона, а не вычисляется из пароля. Любой, у кого в руках разблокированный телефон, увидит записи.
- Резервные копии в этом режиме тоже без пароля; их можно восстановить на другом телефоне.
- Включить пароль обратно можно там же: база не перешифровывается, просто снова защищается вашим паролем.

## 3. Дерево: папки и заметки

Главный экран — список записей текущей папки. Сверху цепочка «Главная › Работа › 2026 › Ноябрь…»: нажмите на любое звено, чтобы перейти туда.

**Панель сверху:** назад, создать заметку (`+`), создать папку, голосовая заметка (микрофон), правка выбранной записи (карандаш), поиск, шаблоны. Остальное — в меню ⋮.

**Действия с записью.** Долгое нажатие открывает меню: открыть, переименовать, свойства, напоминание, копировать (в том числе со всем содержимым), переместить, «Поместить внутрь…», удалить, «вынести содержимое наверх» (для папок) и другие.

**Порядок записей.** Если в папке ручной порядок, запись можно **перетащить**: зажмите её, и она «приподнимется», затем ведите вверх или вниз. У края экрана список прокручивается сам. Если в папке включена автосортировка, приложение предложит перейти на ручной порядок. Режимы сортировки (по названию, по дате, по напоминанию и т. д.) выбираются в меню ⋮ → «Сортировка» отдельно для каждой папки.

**Вставка из буфера.** Скопированную запись можно вставить в другую папку; для папок есть вариант «со всем содержимым».

**Поместить внутрь.** Чтобы перенести запись в обычную заметку (она сама станет папкой), не создавая подзаметку: нажмите и удерживайте нужную запись → «Поместить внутрь…», найдите папку или заметку поиском и выберите её. Другой путь: у записи выберите «Переместить в другую папку…» (или «Копировать…»), затем нажмите и удерживайте заметку, в которую нужно положить, и выберите «Вставить внутрь».

**Свойства записи.** Иконка из большого набора (поиск по английскому названию, например `car`), цвет иконки, цвет фона и текста строки, теги, переменные папки.

**Как организовать дерево.** Типичная схема для ведения дел по дням: `Работа / 2026 / Ноябрь / 21.11.26`. Года и месяцы — обычные папки, день — папка с датой в названии (см. «Даты папок дней» в разделе 6). Для личных данных удобны отдельные верхние папки: «Расходы», «Квартира», «Машина», «Здоровье».

## 4. Редактор заметки

- **Название и текст.** Если название пустое, в списке показывается начало текста.
- **Автосохранение.** Изменения сохраняются сами; при выходе по «Назад» с несохранёнными правками приложение спросит.
- **Оформление:** жирный, курсив, подчёркнутый, зачёркнутый, размер шрифта, цвет текста и фона, выравнивание, маркированный и нумерованный списки, «сбросить оформление».
- **Правка текста:** отмена и повтор, дублировать и удалить строку, выделить всё.
- **Список-чеклист.** Заметку можно превратить в список пунктов с галочками; отмеченное можно удалить разом.
- **Ссылки и телефоны.** Адреса сайтов и номера телефонов из текста появляются кнопками под названием заметки: нажмите, чтобы открыть или позвонить. Ссылки на другие заметки описаны ниже.
- **Шаблон.** Кнопка шаблонов вставляет готовый текст в место курсора.
- **Напоминание, фото, геонапоминание** — кнопки в панели редактора (последнее — в модуле «Напоминания по месту»).
- **Поля.** Строки вида `Поле: значение` — основа переменных, отчётов и модулей. Когда вы набираете `Поле:` в начале строки, приложение подсказывает значения из списка (см. раздел 14).
