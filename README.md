# МоиЗаметки (MyNotes)

Личное приложение для заметок под Android: дерево папок, шифрованная база, шаблоны, аналитика.
Импорт старой базы из MyTreeNotes (`.mtnt`).

## Что есть сейчас (этап 1)

- пароль при входе; база шифруется SQLCipher (AES-256), ключ базы хранится только под паролем;
- дерево папок и заметок, редактор с автосохранением, поиск;
- импорт открытого экспорта `.mtnt` в отдельную папку «Импорт MyTreeNotes …»;
- нет разрешения INTERNET, резервное копирование Android отключено, скриншоты экрана запрещены;
- автоблокировка через 30 секунд в фоне.

## Сборка

APK собирает GitHub Actions (`.github/workflows/build.yml`): вкладка Actions → последний запуск → Artifacts → `MyNotes-debug-apk`.
Локально: Android Studio, открыть корень репозитория.
