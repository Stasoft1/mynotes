# Папки и заметки
Главный экран показывает записи текущей папки. Сверху цепочка «Главная › Работа › 2026 › Ноябрь…»: нажмите на любое звено, чтобы перейти туда.

## Верхняя панель
Назад, создать заметку, создать папку, голосовая заметка (микрофон), правка выбранной записи, поиск, шаблоны. Остальное в меню ⋮.

## Действия с записью
Долгое нажатие открывает меню: открыть, переименовать, свойства, напоминание, копировать (в том числе со всем содержимым), переместить, «Поместить внутрь…», удалить и другие.

## Порядок записей
Если в папке ручной порядок, запись можно перетащить: зажмите её и ведите вверх или вниз. Режимы сортировки (по названию, по дате, по напоминанию) выбираются в меню ⋮ → «Сортировка» отдельно для каждой папки.

## Поместить внутрь
Чтобы перенести запись в обычную заметку (она сама станет папкой), не создавая подзаметку: удерживайте нужную запись → «Поместить внутрь…», найдите заметку поиском и выберите её.

## Свойства записи
Иконка из большого набора, цвет иконки, цвет фона и текста строки, теги, переменные папки. В свойствах заметки есть её ID и кнопка «Копировать ссылку» ({{links|Ссылки между заметками}}).

## Как организовать дерево
Типичная схема для ведения дел по дням: «Работа / 2026 / Ноябрь / 21.11.26». Года и месяцы обычные папки, день папка с датой в названии (от неё заметки получают дату для отчётов). Для личных данных удобны отдельные верхние папки: «Расходы», «Квартира», «Машина», «Здоровье».
