# Пароль и безопасность
- При первом запуске нужно придумать пароль. Им шифруется вся база (SQLCipher, AES-256). **Если забыть пароль, данные восстановить нельзя.** Запишите его в надёжном месте.
- Вход можно ускорить отпечатком пальца (Настройки → «Безопасность»). Отпечаток только открывает приложение.
- Приложение блокируется через 30 секунд после ухода в фон.
- Скриншоты внутри приложения запрещены, облачное резервирование Android отключено.
- Интернет ядру приложения не нужен. Он нужен только модулям, которые вы включите сами (карта, ИИ-разбор голоса).

## Пароль можно выключить
Настройки → «Безопасность» → «Защита паролем». Чтобы выключить, нужно ввести текущий пароль или подтвердить отпечатком. После выключения приложение открывается сразу. База остаётся зашифрованной, но ключ хранится в защищённой области телефона. Включить пароль обратно можно там же.

Если пароль забыт, а вход всегда по отпечатку: пока приложение открыто, зайдите в Настройки → «Безопасность», выключите защиту отпечатком, а затем включите её снова с новым паролем.
