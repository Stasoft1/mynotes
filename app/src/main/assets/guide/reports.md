# Отчёты и проверка показаний
## Отчёт
Меню ⋮ → «Отчёт». Это таблица по переменным папки:
- строки: папки дней выбранного периода (по дате в названии);
- столбцы: ваши переменные, набор настраивается;
- можно добавить расчётный столбец с формулой;
- период: свои даты, «Этот месяц», «Прошлый», «Этот год», «Всё»;
- результат можно отправить через «Поделиться».

Пример. В папке «Расходы» объявлена переменная «Сумма». Откройте «Расходы» → ⋮ → «Отчёт», период «Этот месяц»: получите таблицу «день — сумма» по каждому дню ноября.

Как объявить переменные: {{vars|Переменные и подсчёты}}.

## Проверка показаний
Меню ⋮ → «Проверка показаний» ищет значения, которые не вписываются в рост по датам: опечатки («Показание: 21340» вместо «12340») и случаи, когда вместо показания записали пробег за день. Проверяются текущая папка и вложенные.
