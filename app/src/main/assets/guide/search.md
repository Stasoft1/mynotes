# Поиск
Кнопка с лупой в верхней панели.
- Ищет по названию и тексту, без учёта регистра (в том числе для русских букв).
- Можно писать несколько слов: найдутся заметки, где есть все слова, в любом порядке.
- Совпадения подсвечиваются, под названием виден фрагмент текста вокруг первого найденного слова.
- Фильтры под строкой: «Всё / Заметки / Папки» и по давности правки (любая дата, неделя, месяц, год).
- Поиск идёт по всей базе, а не только по текущей папке.

Пример. «Заправка газпром» найдёт все заметки, где есть оба слова.
