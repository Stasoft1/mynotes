# Внешний вид и настройки
Настройки разделены на группы:
- **Внешний вид:** тема (как в системе, светлая, тёмная), стиль кнопок, значок приложения, обои.
- **Безопасность:** защита паролем, вход по отпечатку ({{security|Пароль и безопасность}}).
- **Данные и копии:** резервные копии, импорт, проверка показаний ({{backup|Резервные копии}}).
- **Подсказки значений:** списки для полей ({{hints|Подсказки значений полей}}).
- **Модули** и **Настройки модулей** ({{modules|Обзор модулей}}).
- **О программе:** версия и сведения о том, где хранятся данные.

## Обои
Настройки → «Внешний вид» → «Обои». Выберите одну из шести картинок: она станет фоном списка и редактора. Ползунок «Прозрачность» задаёт, насколько проявлена картинка (по умолчанию 40%): чем меньше, тем бледнее фон и лучше читаются заметки. «Без обоев» возвращает обычный фон.

## Значок приложения
Шесть вариантов; по умолчанию стоит «Японский».
