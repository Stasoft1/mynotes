# Оглавление
Это руководство лежит прямо в вашей базе: обычные заметки и папки, между которыми можно переходить по ссылкам. Коснитесь синей ссылки в тексте и на появившейся панели нажмите «Перейти» (в режиме просмотра, кнопка «глаз», достаточно коснуться). Кнопка «Назад» вернёт вас обратно сюда, а не на уровень выше. Когда руководство станет не нужно, удалите папку «Руководство».
