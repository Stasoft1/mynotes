# Подсказки значений полей
Когда вы набираете в начале строки «Поле:», над клавиатурой появляются кнопки со значениями из списка этого поля. Нажали, и значение подставилось.

Списки создаются в Настройках → «Подсказки значений»: название поля (например, «Магазин») и значения по одному в строке.

Пример. Поле «Магазин»: «Пятёрочка», «Магнит», «Лента». Теперь при вводе «Магазин:» вы выбираете магазин одним нажатием, а опечаток нет. Значит, итоги по магазинам считаются точно.

Поле «Категория:» подсказывает значения само, если включён модуль {{budget|Бюджет и расходы}}.
