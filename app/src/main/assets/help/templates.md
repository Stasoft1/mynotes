# Шаблоны

Шаблон — готовый текст для создания новой заметки или вставки. Бывают общие (для всех папок) и папочные (только в данной папке).

## Как создать

1. Кнопка шаблонов на верхней панели → «+».
2. Задайте название в меню, название заметки (то, что окажется в заголовке) и текст.
3. Строки вида `Поле: ` создают поля: их удобно заполнять вручную или голосом, и по ним считаются переменные.

Нажатие на шаблон создаёт новую заметку из него; карандаш открывает шаблон на правку.

## Подстановки

| Запись | Что подставится |
|---|---|
| `{сегодня}` | дата 15.11.26 |
| `{дата}` | дата 15.11.2026 |
| `{время}` | время 09:05 |
| `{переменные}` | строки «Поле: » для всех переменных текущей папки |
| `{Имя}` | текущее значение переменной с таким именем (например, `{Пробег}` — последнее известное показание) |

## Примеры

**Заправка.** Название заметки: `Заправка {сегодня}`.

```
Дата: {дата}
Литры: 
ЦенаБ: 
Пробег: {Пробег}
```

**Расход.**

```
Магазин: 
Сумма: 
Категория: 
Дата: {дата}
```

**Показания счётчиков** (для модуля «Коммунальные услуги»):

```
Электричество: 
Вода холодная: 
Вода горячая: 
Дата: {дата}
```

## Советы
- Название шаблона говорите голосом: «новая заметка заправка…» (см. справку «Голосовой ввод»).
- Если у вас папки по дням, подключите модуль «Папка дня»: он сам создаст нужные заметки из шаблонов каждый день.
