# ИИ-разбор голоса (GigaChat)

**Для чего.** Обычный голосовой ввод разбирает фразы по правилам: находит шаблон по названию и раскладывает числа по полям. Если фраза сказана «не по форме», правила могут не справиться. Тогда её разберёт нейросеть GigaChat (Сбер): сама определит шаблон и значения полей.

**Как включить.** Настройки → Модули → «ИИ-разбор голоса (GigaChat)»; ключ — в Настройки → Настройки модулей → «Голосовой ввод».

## Что нужно
- Свой **ключ GigaChat API** (его выдаёт Сбер; вводится в Настройки → Настройки модулей → «Голосовой ввод», кнопка «Ввести ключ…»).
- Доверие к корневому сертификату Минцифры (приложение предложит его принять, если соединение не устанавливается).
- Интернет.

## Как это работает
1. Вы диктуете: «вчера заправился на заправке газпром, взял сорок литров по семьдесят шесть, на счётчике пятьдесят четыре пятьсот».
2. Если правила не нашли шаблон, приложение отправляет в GigaChat **только текст фразы** и **названия ваших шаблонов**.
3. Ответ раскладывается по шаблону, и вы видите заметку перед сохранением.

Содержимое ваших заметок на сервер не отправляется. Если модуль выключен или ключа нет, ничего никуда не уходит. Тот же ключ помогает подобрать значок для заметки, когда вы говорите незнакомое слово («установи иконку …»).

## Советы
- Проверяйте распознанные числа перед сохранением.
- Для частых фраз проще завести шаблон с понятным названием: правила разберут его без интернета.
