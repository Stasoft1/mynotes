# Папка дня

**Для чего.** Если вы каждый день ведёте папку с датой («21.11.26»), приложение создаёт её само вместе с нужными заметками. Утром не надо ничего заводить: открыли приложение — папка и шаблоны на месте.

**Как включить.** Настройки → Модули → «Папка дня»; настройки — в Настройки → Настройки модулей → «Папка дня».

## Что нужно заранее

Хотя бы одна папка дня, созданная вручную, например «Работа / 2026 / Ноябрь / 20.11.26». По ней приложение узнаёт, где создавать новые папки и в каком формате писать дату (`20.11.26`, `20.11.2026` или `20.11.26 - заметка`).

## Как это работает

В новый день, при открытии приложения, рядом с последней папкой дня появляется папка с сегодняшней датой, а в ней — заметки из выбранных вами шаблонов. Папка создаётся в той же папке, где лежит самая поздняя папка дня. Поэтому в начале нового месяца или года сначала создайте первую папку дня вручную (в папке «Декабрь», «2027»), а дальше приложение продолжит само. Если папка сегодняшнего дня уже есть, но пуста, приложение один раз наполнит её заметками из шаблонов.

## Настройки

- **Шаблоны:** отметьте шаблоны, из которых нужно создавать заметки (например, «Заправка», «Работа», «Расходы»).
- **График:**
  - «Каждый день»;
  - «По дням недели» — отметьте дни (Пн–Вс);
  - «N через M» (два через два, три через три…) — выберите первый рабочий день; в остальные дни папка не создаётся.
- Внизу видны ближайшие даты создания, чтобы проверить график.
- Кнопка «Создать папку сегодняшнего дня сейчас» работает в любой день, даже если график её не предполагает.

## Если папка не создалась
Проверьте: модуль включён; график разрешает сегодняшнюю дату; есть папка дня с датой в названии; приложение открыто хотя бы раз за день и разблокировано.
