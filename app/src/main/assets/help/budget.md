# Бюджет и расходы

**Для чего.** Собирает ваши траты и доходы из обычных заметок в отчёт: сколько потрачено за месяц, на что, что крупнее всего, укладываетесь ли вы в лимиты. Отдельных «записей о тратах» нет: расход — это обычная заметка со строками «Поле: значение».

**Как включить.** Настройки → Модули → «Бюджет и расходы». Меню ⋮ главного экрана получит пункт «Бюджет…», а в Настройках → «Настройки модулей» появится раздел «Бюджет».

## Как записывать расход

Создайте заметку (лучше по шаблону, чтобы поля были готовы) и напишите:

```
Магазин: Пятёрочка
Сумма: 450
Категория: Продукты
Дата: 21.11.2026
```

- «Сумма» — число (можно «1 200» и «75,65»).
- «Категория» — любая; при вводе «Категория:» приложение подскажет ваши категории из настроек.
- «Дата» необязательна: без неё берётся день создания заметки. Можно в форме «21.11» (год — текущий) и «21.11.26».
- **Что считается тратой:** заметка, где «Сумма:» стоит вместе с «Категория:» или «Магазин:», либо где есть поле «Расход:». Заметка только с «Сумма:» (оклад, счёт, заправка) в бюджет не попадает — так бюджет не путается с другими вашими данными.

Короткая форма тоже работает:

```
Расход: 450
Категория: Такси
```

## Как записывать доход

```
Доход: 50000
Категория: Зарплата
```

Доходы учитываются отдельно и входят в баланс месяца.

## Что вы увидите

Откройте «Бюджет…» в меню ⋮. Для выбранного месяца показаны:
- расходы, доходы и баланс;
- сравнение с прошлым месяцем (на сколько процентов больше или меньше);
- траты по категориям с полосками;
- график нарастающего итога по дням (видно, когда «ушли» деньги);
- пять самых крупных трат.

Кнопка «CSV» отправляет все записи в таблицу для Excel.

## Лимиты по категориям

Настройки → Настройки модулей → «Бюджет». По строке на категорию, лимит через «=»:

```
Продукты = 20000
Транспорт = 5000
Развлечения = 8000
Прочее
```

Строка без «=» — категория без лимита (она просто подсказывается при вводе). Когда траты категории достигают лимита за месяц, приходит уведомление, один раз в месяц.

## Советы
- Заведите шаблон «Расход» с полями «Магазин:», «Сумма:», «Категория:» — запись займёт несколько секунд, а голосом можно сказать «новая заметка расход, магазин Пятёрочка, сумма 450, категория продукты».
- Если траты не видны в отчёте, проверьте: есть ли рядом с «Сумма:» поле «Категория:» или «Магазин:», и верна ли дата.
- Для итога «по папке» (например, за год) пригодятся ещё и переменные: объявите «Сумма» в папке «Расходы» (см. справку «Переменные»).
