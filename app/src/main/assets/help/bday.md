# Дни рождения и даты

**Для чего.** Ежегодные даты из ваших заметок: сколько дней осталось, сколько человеку исполнится лет. Уведомление за день и в день события.

**Как включить.** Настройки → Модули → «Дни рождения и даты». Окно «Сроки и даты…» (меню ⋮), вкладка «Дни рождения».

## Как записывать

День рождения:

```
ДР: Мама
Дата: 12.05.1965
```

Если указан год, показывается возраст («исполнится 61»). Год необязателен: «Дата: 12.05».

Другая ежегодная дата:

```
Событие: Годовщина свадьбы
Дата: 03.09.2012
```

## Что вы увидите

Список по порядку ближайших дат: имя, дата, через сколько дней, возраст. На вкладке «Ближайшее» эти даты показываются вместе с платежами и гарантиями. Уведомление приходит за день до даты и в сам день.

## Советы
- Для каждой даты нужна своя заметка с «ДР:» (или «Событие:») и «Дата:». Кнопка «+ Добавить» создаёт её за несколько секунд.
